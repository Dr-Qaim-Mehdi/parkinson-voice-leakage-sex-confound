# Voice-based Parkinson's disease detection: speaker leakage and sex confounding

Analysis code, derived result tables and per-recording out-of-fold predictions for two companion manuscripts
by Q. M. Rizvi, W. M. Naqvi, G. V. Mishra, S. Talat and K. Kaur:

1. **How Much of Voice-Based Parkinson's Disease Detection Is Speaker Recognition? A Protocol-Controlled Leakage Audit in Two Corpora** (`paper1_speaker_leakage/`)
2. **Sex as a Confound in Voice-Based Parkinson's Disease Detection: Direct Measurement in a 252-Speaker Cohort** (`paper2_sex_confound/`)

Both analyse two public UCI corpora; no result is reported in both papers.

## Data (public; not all redistributed here)

| Corpus | Source | In this repository |
|---|---|---|
| Oxford Parkinson's Disease Detection Dataset (195 recordings, 32 speaker codes) | https://archive.ics.uci.edu/dataset/174/parkinsons (Little et al., 2009) | `paper1_speaker_leakage/analysis_dataset.csv` (verified row-for-row against the UCI file) |
| Parkinson's Disease Classification dataset (252 speakers, 756 recordings, sex recorded) | https://archive.ics.uci.edu/dataset/470/parkinson+s+disease+classification, doi:10.24432/C5MS4X (Sakar et al., 2019) | **No.** Download it yourself; `paper2_sex_confound/code/common.py` checks its SHA-256 and 14 structural facts before use |

Please cite the original dataset papers when using either corpus.

## Contents

### `paper1_speaker_leakage/` (Oxford corpus, run scripts from this directory)

| Script | Produces |
|---|---|
| `code/rev1_oof.py` | Protocol A (record-wise 10-fold, 3 seeds) and Protocol C (leave-one-subject-out) out-of-fold predictions for 11 nested-tuned classifiers |
| `code/rev1b_protocolB.py` | Protocol B (subject-wise group 8-fold) |
| `code/rev2_analyses.py` | Speaker-level aggregation, Clopper-Pearson intervals, calibration, F0-band stratification, speaker-level bootstrap, predictive values |
| `code/rev3_attribution.py` | Group-aware permutation importance |
| `code/rev4_permutation.py` | Speaker-level label-permutation test |
| `code/rev5_figures.py` | Figures 7-9 of the analysis bundle |

Derived tables (`rev_*.csv`, `rev_*.json`), `out_of_fold_predictions.csv` (every downstream analysis consumes this) and `figures/` are included. `rev_oof.pkl` (about 60 MB) is regenerated by `rev1_oof.py` and is not shipped.

### `paper2_sex_confound/` (Sakar corpus, plus the Oxford F0-proxy analysis)

`code/` has the nested speaker-disjoint runs (`run_nested.py`), cross-sex transfer, the confound dose-response, univariate and power-matched analyses, the Oxford F0-proxy analysis, summarisers and figure scripts. `oof_predictions/` holds one `.npz` per run (diagnosis, sex recovery, within-sex, transfer and all 40 dose-response draws); `results/` holds the final JSON summaries the manuscript quotes; `figures/` the figures.

## Not yet included (documented gaps)

Scripts for these Paper 1 analyses are not in this release; their numbers are reported in the manuscript but cannot yet be regenerated from this repository:

- the speaker re-identification, nearest-neighbour and ICC(1) analyses (both corpora);
- the replication-cohort record-wise (Protocol A) runs and the 252-fold leave-one-subject-out check (the replication cohort's speaker-disjoint runs are `paper2_sex_confound/code/run_nested.py`, which reuses the same model definitions);
- the repetition-depth (thinning) experiment;
- the scripts for Figures 1-6 of the analysis bundle (images are included).

They will be added in a later version of this repository.

## Environment

`requirements.txt` pins the library versions used (also in `paper1_speaker_leakage/versions.json`). All analyses ran on CPU only (no GPU or CUDA) on a MacBook Air (Apple M4, 16 GB memory); estimators are scikit-learn / XGBoost (histogram tree method), with fixed random seeds.
